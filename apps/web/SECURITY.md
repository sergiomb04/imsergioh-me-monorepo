# Política de Seguridad 🔒

## Versiones Soportadas

Actualmente se proporciona soporte y actualizaciones de seguridad para la última versión de la rama principal (`main` / `dev`).

| Versión | Soportada          |
| :------ | :----------------- |
| > 0.1.x | :white_check_mark: |

## Reporte de Vulnerabilidades

Si descubres una vulnerabilidad de seguridad o un problema potencial de exposición de datos:

1. **Por favor NO abras un Issue público.**
2. Envía un correo electrónico o contacta directamente por mensaje privado al mantenedor del proyecto (o a través del servidor oficial de Discord indicado en el sitio web).
3. Incluye una descripción detallada del problema, los pasos para reproducirlo y el impacto potencial.

Nos comprometemos a revisar y corregir cualquier reporte de vulnerabilidad con la mayor brevedad posible.
